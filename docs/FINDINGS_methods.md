# Move-feature associations

Updated 7 September 2026. Generated by `scripts/render_research_notes.py` from the linked result JSON. Older snapshots and superseded interpretations remain in Git history.

Experiment 26 includes 18,296 positions meeting a common minimum 100cp gap: 5,155 with Maia p_max <=5%, 10,443 intermediate and 2,698 with p_max >=30%. Classification uses only the 7,853 extreme-group positions. Thirty binary features yield AUC 0.851, fold SD 0.007, in five folds grouped by game.

| Feature | At most 5% | Intermediate | At least 30% |
|---|---:|---:|---:|
| offers_material | 20.5% | 9.2% | 5.4% |
| quiet | 87.2% | 79.8% | 49.4% |
| deep_retreat | 7.8% | 5.9% | 4.5% |
| to_rim | 38.9% | 30.9% | 26.4% |
| is_capture | 10.9% | 16.3% | 43.4% |
| gives_check | 3.9% | 5.5% | 11.3% |
| escapes_attack | 10.5% | 17.5% | 26.8% |
| creates_threat | 24.8% | 34.3% | 38.4% |

The groups share a threshold, not identical stakes or matched covariates. Their actual exact-match rates are 23.3%, 40.9% and 62.3%; these are associations in different positions, not controlled estimates of why people miss moves. Feature labels derive from Maia probabilities. The classifier itself is linear, but its target depends on a neural model.

The material-exposure feature is an attack/value proxy; it does not evaluate compensation. The legacy extractor can misclassify en passant because it uses destination occupancy. Quiet moves may lead to forcing tactical sequences. The observed trends do not establish a cognitive mechanism or rule out threshold artefacts.

A stronger next comparison should match or adjust for evaluation gap, absolute position evaluation, phase, player rating, time control and source batch, then validate against real human move-quality outcomes on held-out games. See the [learning protocol](LEARNING_STUDY.md) for the intervention needed to test teaching effectiveness.
