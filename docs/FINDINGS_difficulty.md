## Embedding comparison

Experiment 31 reruns experiment 20A on 1,745 positions from 1,341 games. PCA and scaling are fitted using training folds only. Five-fold standard deviations are not confidence intervals.

| Predictor | Mean AUC | Fold SD |
|---|---:|---:|
| surface only | 0.588 | 0.068 |
| Maia only | 0.585 | 0.033 |
| engine only | 0.624 | 0.032 |
| embedding only | 0.601 | 0.031 |
| surface + engine + Maia | 0.628 | 0.040 |
| surface + engine + Maia + elo | 0.755 | 0.036 |
| ...+ EMBEDDING | 0.732 | 0.052 |

| Components | Gain over position-only baseline | Gain over rating-aware baseline |
|---|---:|---:|
| 2 | +0.0068 | -0.0015 |
| 5 | +0.0058 | -0.0033 |
| 10 | -0.0016 | -0.0071 |
| 20 | +0.0056 | -0.0065 |
| 40 | -0.0033 | -0.0232 |

No width improved the full rating-aware baseline in this run. That is a limited predictive result, not proof that the embedding is redundant. The width sweep is exploratory rather than nested model selection. Original experiment 19 used a weaker baseline and an earlier evaluation, so its reported gain is not directly comparable.
