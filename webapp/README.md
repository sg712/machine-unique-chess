# Unnamed Concepts — the trainer

Eight chess concepts mined from 123,405 real positions, each one a pattern where a
strong engine is decisively right and essentially no human plays the move.

```bash
conda activate unnamed-concepts
python webapp/app.py            # http://127.0.0.1:5055
```

## Structure

- **Library** (`/`) — eight concepts, each with its measured signature: how many
  positions, how often real players found them, quiet-move share, average human error.
- **Concept** (`/concept/<id>`) — four study prototypes with the engine's line, shown
  without commentary (the patterns are easier absorbed than described).
- **Drill** (`/concept/<id>/drill`) — twelve unseen positions from the same family.
  Feedback names your move, tells you what share of 1900-rated humans play it, and
  steps through the engine's line.
- **Progress** (`/me`) — per-concept solve rates, tied to a six-character code.

## Data

`concepts.json` is generated by `experiments/16_concept_families.py` (clustering) and
`experiments/17_build_concepts.py` (Stockfish lines + Maia move distributions). The app
serves precomputed positions — no engine runs per request, which keeps responses fast
and deterministic.

## Deploying

Any Flask host (Render, Fly, Railway). Set `SECRET_KEY`, put `study.db` on a persistent
volume, and run behind gunicorn: `gunicorn -w 2 'app:app'`.
